### HEX API reference (final — what Part 1 really implements)
- Registry `HEX[t]={name,w,h,unlock,max,weight(def 1),place,hp(stage),quiet,init,ai,dazed?,dmg?,contact?,draw,onKill?}` + optional extras **`moving`** (platform walkers may use moving platforms, never fading ones), **`hint`** (text of the one-time spawn pop-up, default `name+'!'`), **`col`** (its colour). `place`: `'ceiling'` (x = player±rnd(200,360), `y=-40`, AI lowers it), `'air'` (x = player±rnd(220,380), `y=rnd(100,380)`), `'platform'` (random static platform without `p.fx`, wide enough; `e.p=p`, `e.y=p.y-h`; ground spikes `X[]` avoided), or `function(e)` that sets `e.x,e.y,e.p` and returns true/false. Placement is retried up to 6 times; a candidate closer than `HE.minDist` (Euclidean, centres) is rejected; after 6 failures the spawn is silently abandoned and the legacy spawner continues. For `'platform'` the horizontal distance `>minDist` is measured at the actual spawn x, not at the platform centre (deviation: ground platforms are wide).
- Spawn gate (`heSpawn`, Hard only, never when `bs` exists or `st!='play'`): candidates = types with `unlock<=stage` and alive<`max`; alive HE total < (`stage>=HE.lateStage?maxNewLate:maxNew`); then ONE roll `Math.random()<HE.share`; weighted pick; non-quiet types get `burst` + `heHint(t)`.
- `ai(e,px,py)` runs every play tick instead of the legacy chain (also dazed enemies call `dazed(e)` if defined, else the default bob). `dmg(e,d)` runs in `hitE` BEFORE damage (return `<=0` = nothing happens; any other value replaces d). `contact(e,px,py,bot)` is called every tick for every live enemy of that type; truthy = the legacy contact test is skipped (the legacy test also has the `tick-e.born>14` grace and the stomp rule `e.t!=3&&pl.vy>0&&pb<=e.y+12` — reimplement what you need). `onKill(e)` runs at the end of `kill()` (score, combo, drop, `xpUp` already done). `draw(e)` also receives the DEATH-DISSOLVE SNAPSHOT: a copy of every field of `e` with `fl=1,dd=1,born=-99` — it must tolerate that and honour `e.dd` (no eyes/telegraphs).
- Hooks (all exceptions → `heFail`). `HEH.step(px,py)`: once per play tick after the enemy loop, Hard only. `HEH.reset()`: `load(n)` (covers retry / respawn / restartStage / new run), `clearStage()`. `HEH.drawBack()`: after pickups, before enemies. `HEH.drawFront()`: after projectiles `pj`, before the player sprite. `HEH.drawPlayer(px,py)`: right after `dPlayer()` (px,py = interpolated player centre). Each draw hook runs inside its own `c.save()/c.restore()`.
- **`HEH.pjHit[k](q,i,px,py)`** (k = `q.k`): true = handled → the generic hit test is skipped, and the HANDLER must splice `pj[i]` itself when it wants the projectile gone (true without splicing = it keeps flying, e.g. the claw-waves); false = the generic circle test (hurt) runs. **`HEH.blHit` fn(b,i)**: true = star consumed (the loop removes it); respect `tm.p` pierce inside the handler. Both are skipped when `HE_ON==0`.
- `heFail(err)`: `HE_ON=0`, live HE enemies get `a=0` at once; `heSweep` (next `heStep`/`heReset`, never mid-loop) removes HE projectiles (`q.he` truthy or `q.k` having a `pjHit`) and runs the reset hooks once. Give HE projectiles a kind with a `pjHit` or `he:1`. The game then behaves like v31.
- `heHint(t)`: one pop-up per run per type (the set is cleared in `begin()`/`beginAt()`).
